# Agentická platforma

Efektivita je ve standardizaci —
proto organizace vytváří standardizované procesy

---

# Cyklus standardizace

**Pozoruj a analyzuj** → **Navrhni** → **Implementuj** → **Používej** → …

… a znovu **Pozoruj a analyzuj**

---

# Svět je rozmanitý

Platí pravidlo **80 / 20**

V organizaci chceme mít **deterministické procesy** všude, kde je to možné

---

# Co dnes umí LLM / AI

- **chat** — odpovídat na dotazy ze svých znalostí nebo z vyhledávání na internetu
- **agent** — pracovat v konkrétní roli, používat nástroje a samostatně řešit konkrétní úlohu
- **„vibecoding“** — umožnit vyvíjet IT podporu procesů neprogramátorům / poučeným uživatelům

---

# Agent a vibecoding

**Agent**
- API nástroje (MCP)
- používání počítače (*computer use*)
- **nedeterministická** část procesů

**„Vibecoding“**
- jeden z možných úkolů
- produkce **deterministické** podpory procesu

---

# Základní služby agentické platformy

- umožnit využívání AI v organizaci **řízeným způsobem**
- **chat** — zpřístupnit chat uživatelům řízeným způsobem
- **agent** — umožnit běh agenta
- **„vibecoding“** — vyvíjet a nasazovat IT podporu procesů poučeným uživatelům

---

# Agent na platformě

- API nástroje (MCP) pro řízený přístup k interním i externím službám a datům
- **nedeterministická** část procesů
- „vibecoding“ → produkce **deterministické** podpory procesu

---

# Co je vlastně agent

- **systémový prompt** — co má digitální pracovník za úkol
- **model** — na jakém modelu běží
- **nástroje a schopnosti** — přístup k souborům, datům, službám
- **podpora dlouhého běhu** — ukládá stav rozpracovanosti
- **paměť** — různé druhy dat, které si agent pamatuje
- **audit, řízení přístupu**
